\
Response times:\
Group members should aim to respond within a day of messages and calls, and if members are busy when tasked with something they should notify the group. \
\
Meeting Etiquette:\
Everyone should contribute during meetings, where members should avoid interrupting one another, keep a positive attitude, try to give constructive criticism when needed and respond appropriately to criticism, and ask questions with one another when tasks are unclear.\
\
Pull Request Tone:\
Pull requests should be descriptive and clear, concise, focused on making progress and improving, suggesting changes clearly.\
